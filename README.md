# 👋 Hi, I'm Tiago

Brazilian engineer building **tactical-edge tools for the TAK ecosystem**: RF sensing, drone detection and self-hosted communications. I ship independent, officially signed ATAK plugins.

🇧🇷 Engenheiro brasileiro criando ferramentas táticas para o ecossistema TAK: sensoriamento de RF, detecção de drones e comunicações auto-hospedadas.

## What I build

- **RF & SIGINT at the edge**: spectrum analysis, drone/RF detection and direction finding on Android with SDR hardware
- **TAK integration**: plugins that put detections and tracks on the ATAK map via CoT
- **Self-hosted comms**: push-to-talk and video for ATAK without third-party clouds
- **Servers & tooling**: TAK server setups and web dashboards for situational awareness
